# DUFAP Examples

These examples are small SwiftUI flows that can be copied into an app target using the `Dufap` package.

- `CounterExample`: sync actions and immediate UI state.
- `LoginExample`: text input, validation, and privacy-safe logging.
- `AsyncLoadingExample`: async action, service call, and cancellation.
- `NavigationExample`: `@Pathable(.value)` routes with associated values.
- `PluginExamples`: logger, analytics, and tracer plugin patterns.
